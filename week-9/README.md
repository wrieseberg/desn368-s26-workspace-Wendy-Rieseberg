# Echo Trails Product Landing Page

## Project Description

Echo Trails is a fictional monthly digital subscription service designed for travelers and storytellers who enjoy hidden destinations, abandoned places, paranormal stories, and eerie travel experiences. The purpose of this landing page is to introduce the service, showcase membership options, compare subscription tiers, and encourage users to sign up through a subscription form.

## CSS Transform Implemented

I implemented CSS transforms on interactive buttons throughout the site. Buttons scale slightly larger on hover using:
css
transform: scale(1.05);


and slightly smaller when clicked using:
css
transform: scale(0.98);


This provides visual feedback and improves the user experience.


## Table Content Type Chosen

I created a membership comparison table. The table compares subscription tiers, pricing, included features, and the intended audience for each membership option.

## Challenges Encountered and Solutions

One challenge was creating a responsive layout that worked well on both desktop and mobile devices. I used Flexbox and media queries to reorganize content into stacked layouts on smaller screens.

Another challenge was styling the embedded video section so that it visually connected with the heading banner while maintaining a clean layout. This was solved by adjusting borders, spacing, and alignment to create a more cohesive design.

I also spent time refining the mobile experience by resizing text, reorganizing images, stacking membership cards, and improving spacing throughout the page.
